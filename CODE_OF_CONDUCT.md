# Code of Conduct

Our goal is to create a welcoming and respectful community.

Everyone is expected to:

- Be respectful
- Be constructive
- Be patient
- Help newcomers
- Accept feedback professionally

---

## Unacceptable Behaviour

- Harassment
- Hate speech
- Personal attacks
- Trolling
- Spam
- Intentional disruption

---

## Project Decisions

Project maintainers make final decisions regarding

- Features
- Direction
- Merges
- Releases

Please respect those decisions.
s
---

## Enforcement

Repeated violations may result in

- Warning
- Temporary restriction
- Permanent removal from the project
